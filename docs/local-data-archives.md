# Local data archives

Large, machine-local Control Room archives belong under
`.control-room-data/archives/`. The `.control-room-data/` directory is
intentionally ignored by Git and must not be committed.

Name dated archives with an inclusive ISO date range:
`YYYY-MM-DD_to_YYYY-MM-DD`.

The historical MLflow trace archive for 2026-08-05 through 2026-08-12 is
expected locally at:

`.control-room-data/archives/mlflow/2026-08-05_to_2026-08-12/`
